What this tool does — and doesn't — catch

✅ Reliably auto-fixed: AUTO_INCREMENT, ENUM(...), ON UPDATE CURRENT_TIMESTAMP, inline UNIQUE KEY / INDEX / FULLTEXT KEY, BIGINT primary keys, DATETIME/LONGTEXT, stray [span_N] artifacts.
⚠️ Flagged for manual review, not auto-resolved: new tables whose name already exists elsewhere in ONEID (may need a rename or may need to extend the existing table instead — a judgment call), and REFERENCES to tables not in the known registry (may be a typo, or an intentional forward reference to a not-yet-built table). Use the "Copy prompt for Claude" button on any flagged item to get help resolving it in a fresh AI chat.
Runs entirely in your browser — the file never leaves your device except to the PDF/DOCX parsing libraries loaded from jsdelivr/cdnjs. The known-table registry is best-effort (compiled from the ONEID migration history) and may not be 100% exhaustive — always cross-check the final output against your live Supabase schema before deploying.
